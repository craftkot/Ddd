# Пепел и карты — Godot 4 (native port)

**Новая кодовая база**: нативный Godot 4.7.2 + GDScript, полностью отделена от WebView-ветки. `data/game.json` содержит 161 карту, 136 реликвий, 3 класса, 9 событий и 15 этажей пути, экспортированных из прежних оригинальных данных.

Первая версия порта реализует **одиночный игровой маршрут**: выбор класса, связанная карта пути, 1–4 врага, энергию, руку/добор/сброс/изгнание, розыгрыш карточных эффектов, намерения врагов, награды, магазин, привалы и реликвии. Управление через нативные Control-узлы Godot; поддерживаются касания и выбор цели. **Сетевой PvP с AV и контрприёмами ещё не перенесён.** Поэтому APK Godot нельзя считать заменой WebView v0.7; обе версии распространяются отдельно. Использовать локальную игру для тестирования интерфейса и игрового цикла.

## Разработка
Открыть `godot-duel/project.godot` в Godot 4.7.2. Запустить F6/F5 или `godot --headless --path godot-duel --script res://scripts/smoke.gd`. Сборка Android через GitHub Actions workflow `build-ashes-godot.yml`, который скачивает официальные шаблоны экспорта и делает debug APK. Не требуется Node, WebView или Gradle проекта Java.

Android Package ID: `com.ehtid.ashesgodot`, так что новая APK не удаляет старую.

Оригинальный проект, правила и данные принадлежат проекту «Пепел и карты». Графика сочетает оригинальные 2D-изображения, созданные для этого проекта, и рисование интерфейса средствами Godot. Чужие графические ресурсы Slay the Spire не используются.

## Арт-обновление v0.10

Арты действительно встроены в исходники и в Android APK, а не подгружаются по сети.

- `assets/generated/ashes_painted_atlas.webp` — компактный атлас с 3 героями, 6 типами противников и 12 вариантами оригинальных изображений для карточек и реликвий.
- `assets/generated/ashes_bloodmoon_arena.webp` — отдельный фон готической арены под кровавой луной, отредактированный и сжатый для мобильного рендеринга.
- `scripts/painted_assets.gd` — единая таблица регионов для выборки спрайтов.
- `scripts/actor.gd` — герои на экране выбора классов.
- `scripts/combat_board.gd` — персонажи, сцена боя и иллюстрации на картах.
- `scripts/rune_art.gd` — иллюстрации в наградах и магазине.
- `scripts/main.gd` — фон меню, реликвии в магазине и сундуках.

Из одного атласа процедурно выбираются иллюстрации для 161 карты. Это **12 переиспользуемых артов**, а не 161 уникальная иллюстрация. Качество художественного пакета пока ограничено размером мобильного атласа. Вся графика доступна без интернет-соединения.

CI проверяет, что игровые изображения действительно импортированы Godot, присутствуют на нужных сценах и входят в экспортируемый Android-пакет. UI на физических устройствах пока не проверен.
