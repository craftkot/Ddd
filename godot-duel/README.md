# Пепел и карты — Godot 4 (native port)

**Новая кодовая база**: нативный Godot 4.7.2 + GDScript, полностью отделена от WebView-ветки. `data/game.json` содержит 161 карту, 136 реликвий, 3 класса, 9 событий и 15 этажей пути, экспортированных из прежних оригинальных данных.

Первая версия порта реализует **одиночный игровой маршрут**: выбор класса, связанная карта пути, 1–4 врага, энергию, руку/добор/сброс/изгнание, розыгрыш карточных эффектов, намерения врагов, награды, магазин, привалы и реликвии. Управление через нативные Control-узлы Godot; поддерживаются касания и выбор цели. **Сетевой PvP с AV и контрприёмами ещё не перенесён.** Поэтому APK Godot нельзя считать заменой WebView v0.7; обе версии распространяются отдельно. Использовать локальную игру для тестирования интерфейса и игрового цикла.

## Разработка
Открыть `godot-duel/project.godot` в Godot 4.7.2. Запустить F6/F5 или `godot --headless --path godot-duel --script res://scripts/smoke.gd`. Сборка Android через GitHub Actions workflow `build-ashes-godot.yml`, который скачивает официальные шаблоны экспорта и делает debug APK. Не требуется Node, WebView или Gradle проекта Java.

Android Package ID: `com.ehtid.ashesgodot`, так что новая APK не удаляет старую.

Оригинальный проект, правила и данные принадлежат проекту «Пепел и карты». Графика программно строится Godot; нет заимствованных ресурсов Slay the Spire.
