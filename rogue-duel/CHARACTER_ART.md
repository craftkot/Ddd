# Пепел и карты — персонажи v0.9

## Подлинные изображения в APK

В `app/src/main/assets/art/characters/` включены девять **новых**
RGBA WebP 420×420. Они созданы для этого проекта единым
ассистированным генеративным арт-процессом и обработаны для мобильного
экранного рендера: индивидуальная обрезка, одинаковое поле кадра, сохранение
альфа-канала, оптимизация WebP. **Это не стоковые PNG Kenney и не ресурсы
сторонней игры**, копирования ассетов Slay the Spire нет.

| ID | Роль на экране |
| --- | --- |
| guard | Страж: латный рыцарь с мечом и щитом |
| oracle | Оракул: заклинательница в фиолетовой мантии |
| hunter | Ловчий: зелёный плащ, колчан и лук |
| bandit | Разбойник: два клинка, дорожный плащ |
| cultist | Культист: ритуальная маска и посох |
| skeleton | Скелет-воин: ожившие останки в доспехах |
| slime | Болотная тварь: чудовище из слизи и корней |
| hound | Пепельная гончая: волкоподобная тварь |
| boss | Король мёртвых: массивный тёмный доспех и клинок |

Технические `mage` и `knight` используют существующие изображения
`cultist` и `skeleton`. У них нет отдельных уникальных иллюстраций.

## Стили и лицензионные источники

Перед разработкой проверены предложения:
- https://www.autosprite.io/free-sprite-sheets — бесплатные PNG под CC0,
  но пиксельный стиль не совпадает с уже используемой нарисованной ареной;
- https://kenney.nl/assets/monster-builder-pack — CC0,
  подходит для малых монстров, но выглядит проще;
- https://opengameart.org/ — качество и лицензия зависят от конкретного
  автора и набора.

Изображения перечисленных сайтов **не копировались в v0.9**.
В работе v0.8 уже включены реальные Kenney CC0 PNG для фэнтези-рамок,
предметов, иконок и окружения; их авторство и CC0 описаны в
`ASSET_CREDITS_AND_NETWORK.md`.

## Отображение

`atelier.js` выбирает локальный `art/characters/<id>.webp`, без сетевых
запросов; `character-redesign.css` адаптирует пропорции и тени для
разрешений телефона. Никаких новых прав Android не требуется.

Анимация «дыхания» сделана CSS и автоматически отключается при
`prefers-reduced-motion`. Это НЕ полноценные покадровые idle/attack/hurt.
Прицеливание и затухание погибших используют только CSS, без изменений
системы боевого урона.
