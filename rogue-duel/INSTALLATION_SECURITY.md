# Установка «Пепел и карты» на Android — v0.11 (beta)

## Что изменилось

- Launcher icon: `app/src/main/res/drawable-nodpi/ashes_launcher.webp` и
  `res/mipmap-anydpi-v26/ic_launcher.xml` — адаптивный значок с Оракулом.
- Обложка стартового экрана: `app/src/main/assets/art/ashes-cover.webp`.
- `targetSdkVersion=35` (Android 15), `minSdkVersion=26` (Android 8).
- Единственное разрешение: `android.permission.INTERNET`.
- WebView: включён Safe Browsing, отключены file/content access и mixed content.
  Вся HTML/JS/CSS-графика игры загружается из локальных ресурсов; посторонние
  HTTPS-страницы и внешние скрипты не могут получить доступ к AndroidNet bridge.
- GitHub Release содержит `SHA256SUMS.txt` для проверки целостности APK.

## Что означает предупреждение Android

**«Приложение создано для старой версии Android».**
Одна из причин — `targetSdk` значительно ниже версии системы. Мы изменили
32 → 35. Само по себе это не гарантирует совместимость со всеми будущими API.

**«Play Protect рекомендует проверить приложение».**
При установке неизвестной APK из браузера Google может запросить сканирование
даже у безопасного приложения. Это решение Android/Google, его нельзя
легитимно выключить внутри нашего APK. Сканирование можно разрешить.

**«Play Protect заблокировал приложение как вредоносное».**
Не советуем обходить блокировку. Проверить конкретное сообщение, разрешения,
хэши и при необходимости подать официальную апелляцию Google.

**«Не удалось установить: конфликт пакетов / подпись».**
Все сборки v0.8–v0.11 Beta пока подписываются `debug`-ключом GitHub Actions,
который может меняться между запусками CI. Android не позволяет обновлять
приложение поверх предыдущей версии при изменении сертификата, даже если
`applicationId` одинаков. Операция удаления приложения уничтожает его
локальные игровые данные, если нет отдельной резервной копии.

## Для нормальных обновлений без удаления данных

1. Сгенерировать **один** долгосрочный keystore для `com.ehtid.ashesduel`
   и хранить оригинал вне GitHub.
2. Поместить его Base64 и пароли в **GitHub Actions Secrets**, не в код.
3. Выпускать через `assembleRelease` с одним и тем же ключом и увеличивать
   `versionCode`.
4. Опционально зарегистрировать сертификат и пакет в
   [Android Developer Console](https://developer.android.com/developer-verification)
   или публиковать через Google Play после проверки.

Без этих шагов релиз остаётся тестовым. Никаких скрытых отключений
Play Protect, установщика пакетов или проверки сертификата мы не делаем.

## Проверка готового APK

1. Сравнить SHA256 скачанного APK со значением в `SHA256SUMS.txt`.
2. Проверить подпись: `apksigner verify --verbose --print-certs app.apk`.
3. Проверить целевой SDK: `apkanalyzer manifest target-sdk app.apk`.
4. Проверить разрешения: `apkanalyzer manifest permissions app.apk`.

**Примечание:** предупреждение «Разрешить установку из этого источника»
показывает сама ОС для APK вне Google Play; убрать его из кода игры нельзя.
